## TryHackMe – Offensive Security Intro

### Status
Completed successfully – 100%

### Platform
TryHackMe

### Overview
In this room, I was introduced to the basic principles of offensive security and ethical hacking.

I worked within a safe and legal simulated banking environment to understand how security professionals identify weaknesses in web applications before malicious attackers can exploit them.

### Tasks Completed

#### Task 1 – Think like a Hacker
I learned that offensive security involves thinking like an attacker in order to identify weaknesses and security vulnerabilities.

The exercise also reinforced the importance of performing security testing only within authorised and controlled environments.

#### Task 2 – Starting the Lab
I launched a simulated web application and became familiar with the testing environment.

This introduced me to working with a virtual lab that represents a real-world web application.

#### Task 3 – Find Hidden Pages
I used a terminal-based directory discovery technique to identify web pages that were not immediately visible through the website.

This helped me understand how attackers and penetration testers perform web enumeration to discover potentially exposed resources.

#### Task 4 – Attack the Admin Page
After identifying a hidden administrative area, I used the weakness within the simulated application to demonstrate how an attacker could gain access to functionality that should have been properly protected.

This showed me why sensitive administrative pages must have appropriate access controls and security protections.

### Skills Practised

- Offensive security fundamentals
- Ethical hacking concepts
- Web application reconnaissance
- Web enumeration
- Terminal usage
- Directory discovery
- Identifying exposed web resources
- Basic vulnerability exploitation
- Understanding access control weaknesses

### What I Learned
This exercise helped me understand a simple offensive security workflow:

**Explore → Enumerate → Identify Weaknesses → Test the Vulnerability**

I also learned that seemingly hidden web pages are not automatically secure and that sensitive administrative functionality should always be protected with proper authentication and access controls.

### Reflection
Completing this practical exercise gave me an introduction to how ethical hackers approach web application security testing.

It helped me understand that offensive security is not simply about attacking systems. It involves identifying weaknesses in an authorised environment so that organisations can understand their risks and improve their security.
