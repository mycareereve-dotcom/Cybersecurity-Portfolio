### Status

### Overview
In this room, I learned the basic principles of defensive cybersecurity and practised responding to a simulated attack against a fictional organisation.

The exercise introduced the type of activities a defensive security professional or SOC analyst may perform when monitoring and protecting systems.

### Tasks Completed

#### Task 1 – Think like a Defender
I learned that defensive security focuses on protecting systems rather than attacking them.

I also learned the importance of detecting suspicious behaviour, investigating potential threats and responding before significant damage occurs.

#### Task 2 – Detect Suspicious Activity
I used a simulated security monitoring dashboard to review recent alerts and identify suspicious network activity.

This exercise helped me understand how SOC analysts distinguish normal activity from potentially malicious behaviour.

#### Task 3 – Identify the Attack
I investigated the suspicious activity further to understand what the attacker was attempting to access.

I reviewed information provided by the monitoring system and used it to identify the nature of the suspicious activity.

#### Task 4 – Stop the Attack
I practised the containment stage of incident response.

After identifying the malicious activity, I applied a security control to block the suspicious source and prevent further activity.

### Skills Practised
- Defensive security fundamentals
- SOC monitoring
- Security alert analysis
- Suspicious activity detection
- Basic incident investigation
- Threat identification
- Incident containment

### What I Learned
This exercise helped me understand the basic workflow of defensive security:

**Monitor → Detect → Investigate → Contain**

I also gained a better understanding of how SOC analysts use security monitoring information to recognise threats and take action to protect an organisation.

### Reflection
Completing this practical exercise gave me an introduction to the responsibilities of a defensive security professional.

It helped me understand that identifying suspicious activity is only the beginning. A security analyst must also investigate what is happening, determine the possible threat and take appropriate action to contain it.
