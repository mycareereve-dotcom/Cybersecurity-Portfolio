### Status

### Overview
In this room, I learned the basic principles of the client-server model and how computers communicate over the web.

I learned that a client is the device or application that sends a request, while the server receives the request, processes it, and sends back a response.

### Tasks Completed

#### Task 1 – Introduction
I was introduced to the client-server model.

I learned that a client can be a browser, application, program, or computer that requests information or services from a server.

I also learned that the server is responsible for receiving the request and returning the requested information.

#### Task 2 – Pizza Delivery
This task helped me understand the client-server model using a simple real-world example.

I learned that the client makes the request, similar to a customer placing an order, while the server provides the requested service, similar to a restaurant preparing and delivering the order.

This helped me understand the difference between the requester and the provider.

#### Task 3 – Web Communication in Practice
In this task, I learned how web browsers communicate with web servers using HTTP.

I learned that HTTP is a stateless protocol, meaning each request is handled separately unless additional mechanisms such as cookies or sessions are used.

I was introduced to HTTP methods including:

- GET
- POST
- PUT
- DELETE
- PATCH
- HEAD
- OPTIONS
- CONNECT
- TRACE

I focused mainly on the GET method, which is used to request information from a web server.

I also used Firefox Developer Tools to inspect network traffic.

I learned how to:

- Open Developer Tools
- Use the Network tab
- Reload a webpage to view requests
- Identify GET requests
- View request headers
- View response headers
- View the response body
- Recognise a successful response using the status code 200 OK

I also learned how a URL is structured.

For example:

`https://www.iamlearning.thm/contact`

can be broken down into:

- `https` – the scheme or communication method
- `www.iamlearning.thm` – the host or server
- `/contact` – the path or requested resource

#### Task 4 – Conclusion
I reviewed the main concepts of client-server communication and web requests.

This helped me understand how browsers request webpages and how servers respond with the requested content.
