## TryHackMe – Inside a Computer

### Status
Completed successfully

### Platform
TryHackMe

### Module
Computer Fundamentals

### Overview
In this practical exercise, I learned about the main hardware components inside a computer and how they work together.

The room used a simulated digital-forensics investigation where I had to identify the correct components, rebuild a workstation, boot the system and recover an evidence file.

### Tasks Completed

#### Identifying Computer Components
I reviewed different computer components and learned their functions and where they are normally installed.

Components covered included:

- Central Processing Unit (CPU)
- Random Access Memory (RAM)
- Power Supply Unit (PSU)
- Network Adapter
- Input / Output Panel
- Solid State Drive (SSD)
- Hard Disk Drive (HDD)
- Graphics Processing Unit (GPU)

#### Rebuilding the Computer
I examined the available components and selected the correct parts needed to rebuild the workstation.

I successfully placed all seven required components into their correct locations.

#### Understanding Hardware Functions
I answered questions about the roles of key computer components.

This helped reinforce my understanding of how hardware components work together to allow a computer to operate.

#### Booting the System
After assembling the machine correctly, I successfully booted the workstation.

#### Evidence Recovery
I accessed the recovered evidence file from the simulated workstation and completed the forensic recovery process.

I then submitted the recovered evidence to the simulated senior analyst.

### Skills Practised

- Computer hardware identification
- Understanding CPU, RAM and storage
- Understanding power supply functions
- Motherboard component placement
- Network hardware awareness
- Computer assembly concepts
- System boot process
- Basic digital-forensics workflow
- Evidence recovery awareness

### What I Learned
This exercise helped me understand that each computer component has a specific role and must work together correctly for the system to function.

I also learned how knowledge of computer hardware can support digital-forensics investigations, especially when examining or recovering evidence from a computer system.

### Reflection
Completing this exercise strengthened my understanding of computer hardware and how the different components connect to the motherboard.

The forensic scenario also helped me see how basic hardware knowledge can be applied during an investigation when recovering information from a computer.
